## M1: semantic foundation

| Requirement | Current evidence | Still required for the exit criterion |
| --- | --- | --- |
| P01: exact build and subject closure | `provium capture-cargo` records actual compiler argument vectors, working directories, observed compiler executable hashes/version, root source inventory/snapshots, and Cargo manifest/lock identity. Root compilation is distinguished from compiler probes. Changed sources and failed builds invalidate capture success. Jarl's host and installed wasm32 release builds have been captured. | Effective cfg/module/macro/type/call/trait resolution; configuration support; generated/dependency inputs and toolchain sysroot attestation; connect resolved subject closure to the verifier rather than merely record commands |
| P02–P03: typed IR and complete primitive coverage | Existing whole-method backends cover selected state operations and some membership operations; progress and project manifests enumerate them. | Complete `State::write`, all membership constructors/queries/quorum helpers, remaining state/storage calls, and all accepted operations/outcomes; no unsupported branch or callee hidden in a root |
| P04: ownership and representation | Logical stores, arrays and source-checked field paths; normal-return destruction continuations | Typed places, moves, borrows/reborrows, alias and initialized-slot rules, plus checked refinement of generated stores to those rules |
| P05–P06: calls, control flow, arithmetic | Selected source-local helper inlining and scalar/pure evaluation with arithmetic contracts | Complete dispatch/library contracts, all loop/call effects and termination, target/profile arithmetic behavior, and caller discharge |
| P07: panic and destruction | Some backends retain drop suspension and partial failure states | Actual destructor/callback effects, unwind rollback, abort-to-crash and every exceptional outcome required by primitive callers |
| P10: start source preservation | Generated IR correspondence and source/build hashes only | Independently checked source interpretation/lowering derivations for the M1 constructs. Hashes and successful rustc compilation are not preservation proofs |
| R01–R05 | Component initialization, capacity, log representation, push/grow/truncate/install/restore contracts | Complete constructor/configuration validation, reachable caller preconditions, hard-state/dirty-delta relation and exact Write-to-durable-checkpoint equivalence |

The new capture command is reusable Provium infrastructure. It runs only installed
Rust tools and locked/offline Cargo; it does not install targets or dependencies.
Only Cargo creates or writes the fresh target tree. Wrapper code, argument
records, source snapshots and reports stay under consumer evidence directories.
Unsupported Cargo configuration and existing wrapper overrides are rejected
explicitly. The report sets `semantic_preservation_proved=false` and is not a
proof certificate. Captured builds do not close P01 by themselves.

Useful current commands:

```sh
cargo test -p jarl --locked --offline --test proofs m1_actual_cargo -- --test-threads=1
cargo run --manifest-path provium/Cargo.toml --locked --offline -- \
  capture-cargo jarl/proofs/builds.json --out jarl/artifacts/provium/m1-capture-host
```

## M2: first global election proof

M2 follows M1; it is not closed by the existing election-deadline component.
Required implementation roots include complete fixed-engine initialization,
`tick`, `step`, campaign/pre-vote/vote handling, `follow`, `become_leader`,
send/reply/materialization and persistence/recovery. Other reachable API actions
need their election-state frame/outcome contracts as well.

The proof must establish R08/R09 and S01/S02 by induction from admissible
initialization over arbitrary histories, including crashes between durable save
and acknowledgment. It must derive durable one-vote-per-term and term monotonicity
from the generated transitions, bind granted replies to persisted votes, discharge
quorum intersection/counting hypotheses, and derive historical leader uniqueness.
No assumption may state those conclusions. Any remaining source-translation trust
must be explicit; M6 remains the full correspondence closure milestone.

No global election theorem has been established yet.
